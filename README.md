# tsmod-hdpack

HD weapon/player models and weapon sounds for The Specialists 3.0, extracted
from the TSMOD.NET repack. Game code is unchanged — these are drop-in asset
replacements.

## Source

All assets were collected from the TSMOD.NET client distribution
("TSMOD.NET - The Specialists"), available at
[tsmod.net](https://tsmod.net). Credit for the HD models and sounds goes to
their original authors and the TSMOD.NET team.

## Install

Copy `models/` and `sound/` over your `ts/` mod directory.

## Contents

- `models/` — HD replacements for every weapon model (`v_`, `p_`, `w_`), the
  7 stock player models (agent, castor, gordon, hitman, laurence, merc, seal)
  and `player.mdl`.
- `sound/weapons/` — replacement sounds for bull, deagle, fnh, glock22, m60
  and mossberg, plus the new glock22 reload sounds the HD `v_glock22.mdl`
  references (`clipin`, `clipout`, `slideback`, `sliderelease`).
